# Features Directory

This directory is reserved for domain-specific feature modules:
- `hero`: Hero presentation and focus tags (Phase 1).
- `quick-review`: 30-60 second recruiter summary drawer (Phase 1).
- `projects`: Filterable project cards and case studies (Phase 1).
- `skills`: Evidence-backed skill explorer (Phase 1).
- `journey`: Indonesia Journey Map and storytelling timeline (Phase 3).
- `hologram`: 3D seated wireframe hologram scene (Phase 2).
- `ai`: Ask Arham AI reviewer copilot panel (Phase 6).
