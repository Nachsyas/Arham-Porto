# AI Specification: Knowledge Sources

- **Purpose**: Define approved knowledge ingestion sources.
- **Current Phase**: Phase 0 (Bootstrap Foundation).

---

## 1. Approved Sources
1. Structured canonical portfolio data (`data/profile/`, `data/projects/`, `data/skills/`, `data/evidence/`, `data/experience/`, `data/education/`).
2. Approved candidate GitHub repositories:
   - `Nachsyas/EduTrace`
   - `Nachsyas/gdgoc-ecommerce`
   - `Nachsyas/maritime-ai-dashboard`
   - `Nachsyas/smart-kitchen-backend`
   - `Nachsyas/smart-kitchen-frontend`
3. Verified architectural documentation and public README files.

---

## 2. Forbidden Ingestion
- `.env`, secrets, credentials, tokens.
- Private personal communications or unapproved repositories.
- Blind indexing of external untrusted code.
