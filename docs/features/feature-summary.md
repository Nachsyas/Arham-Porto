# Feature Specification: Summary

- **Purpose**: High-level inventory of planned portfolio features.
- **Current Phase**: Phase 0 (Bootstrap Foundation).

---

## 1. Feature Map
1. **Hero Section**: Prominent name presentation, Software Engineer role, dynamic focus tags, and dual CTAs.
2. **3D Wireframe Hologram**: Seated human wireframe with subtle scroll-linked rotation (`[-10°, +10°]`).
3. **Quick Review**: 30–60 second recruiter overview panel with top projects, stack, and contact links.
4. **Selected Work & Case Studies**: Evidence-backed project cards with deep-dive case study routing.
5. **Skill Explorer**: `SKILL -> CLAIM -> EVIDENCE -> SOURCE` verification chain without percentages.
6. **Indonesia Journey Map**: Interactive map choreographing personal and educational trajectory.
7. **Ask Arham AI (Reviewer Copilot)**: Grounded Q&A, 60-Second Brief generator, and Job Description comparison.
